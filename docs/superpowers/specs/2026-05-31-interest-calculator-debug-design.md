# 利息计算器调试优化设计

## 目标

修复已发现的计息、LPR、界面状态和打包问题，并新增“每条计算过程”功能，方便使用者按公式手工复验。

## 范围

- 修复 LPR 最近一期取值逻辑，确保取不晚于目标日期的最近记录。
- 分段计息同时按 LPR 变动日和法定利率规则边界拆分。
- 金额和利率计算改用 Decimal，展示和导出统一保留两位小数。
- 新增每条流水的计算过程文本，主界面通过选中流水后弹窗查看，Excel 导出增加“计算过程”列。
- 新增、修改、删除、清空流水后统一刷新明细和汇总。
- 移除源码中的 Tushare token，改为读取环境变量。
- 修正打包配置不依赖根目录中不存在的 lpr_data.json。
- 补齐文档依赖说明。

## 验证

优先运行语法检查和小范围计算验证。当前机器若没有 Python 解释器，则用静态检查和可读公式复核作为替代，并在最终说明中标注未能运行的部分。
